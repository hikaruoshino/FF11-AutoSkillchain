# AutoSkillchain

FFXI(Windower 4)用のアドオンです。侍で、自分またはほかのプレイヤーのウェポンスキルを検知すると、設定した待ち時間のあとに、連携になる次のウェポンスキルを自動で入力します。十一之太刀・鳳蝶(防御力 -25%)を起点にした 6 段光連携と 4 段闇連携を、あらかじめ登録しています。

## 注意

ウェポンスキルを自動で入力します。Windower を含む外部ツールの利用は、FFXI の利用規約では認められていません。アカウントの停止などの措置を受ける可能性があり、使用による不利益について、作者は責任を負えません。自己責任で使い、放置・無人での使用はしないでください。

ゲーム内で確認できる範囲は確認していますが、一人では確認できない範囲もあります。動作の報告をいただけると助かります。

## 動作

メインジョブが侍で戦闘中のときだけ動きます。

1. 自分のターゲットに当たったウェポンスキル(自分のもの、またはほかのプレイヤーのもの)を検知します。
2. ルート 1〜5 では、選んでいるルートの初段の技を検知したときだけ、設定した秒数(同梱のルートは 6.0 秒)待ちます。初段の技が撃たれるまで、何も入力しません。
3. 待ったあと、最大 2.5 秒の間 TP を 0.2 秒ごとに確認し、1000 以上になった時点で `/ws "技名" <t>` を 1 回入力します。TP が足りないまま 2.5 秒たつと、入力せずに初段の待機に戻ります。
4. 入力した技で連携が発生したかを、アクションパケットで確かめます。発生していれば次の段へ進みます。発生していなければ、そこで止めて初段の待機に戻ります。ルートの最後まで進んだときも、初段の待機に戻ります。ルート外のウェポンスキルが撃たれたときも同じです。

ルート 6(自動ソルバー)だけは初段の概念がなく、検知した技の属性から、次の技を選んで入力します。階層はレベル 3 を優先します。連携が起きたかの確認はせず、TP が 1000 以上あるあいだ続きます。侍の技ではないものを選ぶこともあります。

## ルート

| 番号 | 内容 |
| --- | --- |
| 1 | 鳳蝶 → 陣風 → 照破 → 照破 → 花車 → 不動(6 段光連携) |
| 2 | 鳳蝶 → 陣風 → 照破 → 不動(4 段闇連携) |
| 3 | 照破 → 花車 → 不動 |
| 4 | 照破 → 不動 |
| 5 | 雪風 → 月光 → 乱鴉 |
| 6 | 自動ソルバー |

ルート 3〜5 の連携の結果は、ゲーム内での確認をしていません。

ルートは `data/sc_routes.json` で定義しています。付属の `AutoSkillchain_GUI_Editor.html` を PC のブラウザ(Chrome・Edge など)で開くと、段、待ち時間、目標の属性を編集できます。編集したら JSON をダウンロードして、`data/sc_routes.json` に置きます。

## 導入

```text
Windower4/addons/AutoSkillchain/
├── AutoSkillchain.lua
├── AutoSkillchain_GUI_Editor.html
└── data/
    └── sc_routes.json
```

1. このリポジトリのファイルを `Windower4/addons/AutoSkillchain/` に置きます。
2. ゲーム内で `//lua load AutoSkillchain` を実行します。

## コマンド(`//sc`・`//autosc`・`//autoskillchain`)

| コマンド | 内容 |
| --- | --- |
| `//sc route <1〜6>` | ルートを切り替える |
| `//sc route reload` | `data/sc_routes.json` を読み込み直す |
| `//sc route fix` | `data/sc_routes.json` を初期の内容で作り直す(自分で書いたルートは消えます) |
| `//sc reset` | 段階を初段の待機に戻す |
| `//sc reload` | アドオンを読み込み直す |
| `//sc toggle` | アドオン全体の ON / OFF |
| `//sc party` | 自分以外のプレイヤーのウェポンスキルへの追撃の ON / OFF |
| `//sc solo` | 自分のウェポンスキルへの追撃の ON / OFF |
| `//sc delay <1.0〜8.0>` | ルート側に待ち時間が無いときの待ち時間(既定 6.0 秒) |
| `//sc status` | 設定と、選んでいるルートを表示する |

同梱のルートには待ち時間が入っているため、`//sc delay` は効きません。待ち時間は `data/sc_routes.json` の `delay_seconds` で変えます。
