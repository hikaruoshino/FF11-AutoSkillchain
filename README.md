# ⚔️ FFXI-AutoSkillchain (v5.1 Master Edition)

FF11（ファイナルファンタジーXI）のWindower 4用アドオン。  
侍（SAM）のソロ一人連携およびパーティ連携において、**『十一之太刀・鳳蝶』（防-25%）起点から最高階層連携（6段光連携・4段闇連携等）までをミスなく最速で自動追撃・完遂**する完全自動化スクリプトです。

---

## 🌟 主な特徴と機能 (v5.1)

1. **鳳蝶起点 6段光連携 ＆ 4段闇連携 プリセット標準搭載**
   - **ルート 1 (6段光連携)**: `鳳蝶` (トス/防-25%) ➔ `陣風` [炸裂] ➔ `照破` [重力] ➔ `照破` [分解] ➔ `花車` [核熱] ➔ `不動` [光]
   - **ルート 2 (4段闇連携)**: `鳳蝶` (トス/防-25%) ➔ `陣風` [炸裂] ➔ `照破` [重力] ➔ `不動` [闇]
2. **「陣風 ➔ 陣風」ループ誤動の完全解消**
   - 旧設定にあった重複定義を排除し、厳格なステップ管理により `鳳蝶` 検知後は確実に `陣風` ➔ `照破` へ進行します。
3. **連携未成立（ミス/回避）時の自動追撃中断＆安全リセット**
   - アクションパケットの連携エフェクト（`has_add_effect`）をリアルタイム判定。連携が不成立だった場合は即座に追撃を中断し、最初の初段待機状態 (Step 1) へ安全にリセットします。
4. **設定自動復元機能 (`//sc route fix`)**
   - JSON設定ファイルの構文エラーが発生した場合でも、ゲーム内コマンド一発で正常なプリセットファイルへ自動復元可能。
5. **Web GUI 視覚的エディタ同梱 (`AutoSkillchain_GUI_Editor.html`)**
   - PCブラウザ上で連携ステップや待機秒数を視覚的にカスタマイズ・保存できます。

---

## 📁 フォルダ構成・配置方法

```text
Windower4/addons/AutoSkillchain/
├── AutoSkillchain.lua           <-- アドオン本体
├── AutoSkillchain_GUI_Editor.html <-- Web設定エディタ
└── data/
    └── sc_routes.json          <-- 連携ルート設定ファイル
```

1. リポジトリよりファイルをダウンロードします。
2. `Windower4/addons/AutoSkillchain/` フォルダへ配置します。
3. FF11ゲーム内で `//lua load AutoSkillchain` または `//sc reload` を実行します。

---

## 🎮 コマンドリファレンス (`//sc` または `//autosc`)

| コマンド | 説明 |
| :--- | :--- |
| `//sc route <1~6>` | アクティブな連携ルート(1〜6)を切り替えます |
| `//sc route reload` | `data/sc_routes.json` の設定を再読み込みします |
| `//sc route fix` | 壊れた `sc_routes.json` を初期正常データへ自動復元します |
| `//sc reset` | 現在の連携ステップを強制的に初段待機状態 (Step 1) へリセットします |
| `//sc toggle` | アドオン全体の有効/無効を切り替えます |
| `//sc party` | パーティメンバーのWSに対する自動連携追撃の ON/OFF |
| `//sc solo` | 自分自身のWSに対する自動一人連携追撃の ON/OFF |
| `//sc delay <1.0~8.0>` | 連携受付の基本待機秒数を調整します (デフォルト: 6.0秒) |
| `//sc status` | 現在の設定状況と選択中ルートを表示します |
