# AutoSkillchain (v5.5.0)

**ファイナルファンタジーXI（Windower 4 用） 侍の連携の続きを自動で撃つアドオン**

`AutoSkillchain` は、侍（メインジョブ）で戦闘中に、自分またはパーティーの人が撃ったウェポンスキル（WS）を見て、選んだルートに沿った次の WS を予約し、待ち時間のあとに `/ws` を送ります。

* このアドオンがするのは、**連携と集中攻撃のための `/ws` の予約と送信だけ**です。キャラクターの移動・敵への接近・ターゲットの切り替えはしません。
* 技の着弾と連携の発生は、アクションパケットで確かめてから次の段へ進みます。
* 技名は日本語クライアントの名前で照合します（ルートの技名も日本語だけ）。

> **注意（規約）**: 戦闘の操作を自動で繰り返すアドオンは、FFXI の規約に触れるおそれがあります。運営側の検知の有無は確かめられません。使う場合は自己責任でお願いします。

> 放置・無人での使用はしないでください。

> **ゲーム内での確認**: v5.5.0 の公開版は、模擬環境のテストだけで確かめています。ゲーム内では確かめていません。

## 📦 ファイル構成

```text
AutoSkillchain/
├── AutoSkillchain.lua              # アドオン本体
├── libs/
│   └── sc_json.lua                 # ルートの JSON を読む部品（必須）
├── AutoSkillchain_GUI_Editor.html  # ルートの編集画面（ブラウザで開く）
├── README.md                       # 本ドキュメント
└── data/
    ├── sc_routes.json              # ルートの設定（無ければ既定のルートで自動で作る）
    └── settings.xml                # 自動で作る設定ファイル
```

`libs/sc_json.lua` が無いと読み込めません。Windower の `libs/json.lua` は入れ子の配列を読めないため、ルートの JSON はこの部品で読みます。

## 🚀 インストール

1. `AutoSkillchain` フォルダーを `Windower4/addons/` に置きます（`libs/sc_json.lua` を含めて）。
2. ゲーム内で `//lua load AutoSkillchain` を実行します。
3. 読み込むと `loaded v5.5.0 -- ... (ルート1適用中・全体機能: ON)` のように出ます。`全体機能: OFF` と出たら、前に `//sc stop` で止めたままです。`//sc start` で再開します。

## ⚙️ 動き

### 共通
* 動くのは、メインジョブが侍で、戦闘中（抜刀中）のときだけです。
* 見るのは、自分がターゲットしている敵（`<t>`）に当たった WS だけです。
* **始点にするのは、自分（`//sc solo` が ON のとき）とパーティーの人（p1〜p5。フェイスを含む・アライアンスは含まない。`//sc party` が ON のとき）の WS だけ**です。パーティ外の人の WS では始めません。
* 次の WS は、前の WS を見てから待ち時間（初期値 6 秒）のあとに送ります。待ち時間のあと 2.5 秒のうちに送れなければ、送らずに取り消します。
* 送る直前に次を確かめ、合わなければ予約を取り消します: 戦闘中か・行動不能（睡眠・石化・スタン・魅了・アムネジア・テラー・ララバイ）でないか・`<t>` が予約した敵のままか・敵の HP が 0 でないか。
* 敵が遠い（3.5 ＋ 敵の大きさが 2 を超えた分）あいだは送らずに待ちます。TP が 1000 に届かないあいだも待ちます。
* 送ってから 8 秒たっても着弾を確かめられなければ、予約を取り消します。
* 次のどれかで、予約と進行を取り消します: 交戦の解除・戦闘不能・ジョブの変更・エリアの移動・ログアウト・アンロード・`//sc stop`・`//sc reset`・ルートの切り替えと読み直し・ルートに無い WS が入った。

### カスタムルート（`mode: custom`）
* ルートの 1 段目の `trigger_ws` を始点にし、各段の `action_ws` を順に撃ちます。
* 自分が予約して送った WS の着弾で連携が起きたときだけ、次の段へ進みます。連携が起きなければ最初に戻ります。
* 同じ名前の WS でも、手動で撃った WS や、前の予約で送った WS の着弾では進みません。

### 全自動（`mode: auto`・既定のルート 6）
* 始点の WS の属性から、いちばん階層の高い連携になる侍の WS を選んで撃ちます。そのあとは、起きた連携だけから選びます。
* 自分の WS が当たらなかった・連携が起きなかった・連携が閉じた（光→光・闇→闇・極光・黒闇）ときは止めます。

### 草薙剣モード（初期設定は OFF）

草薙剣をメインに装備した侍が `//sc kusanagi on` と入力すると、自分またはパーティーの「十一之太刀・鳳蝶」「参之太刀・轟天」を始点に、「絶之太刀・無名」で連携を続けます。連携が閉じるか失敗すると次の始点を待ちます。無名は一連の連携で最大6回です。

アフターマスがない場合は、始点から最長120秒、TP3000を待って付与用の無名を1回撃ちます。アフターマス中の連携ではTP1000以上で無名を撃ちます。`//sc kusanagi off` で通常ルートに戻り、設定は次回起動時も引き継ぎます。旧版から更新した場合も初期設定はOFFです。

### 集中攻撃（初期設定は ON）

侍で抜刀中、同じ敵を狙う味方PCが自分以外に2人以上いると、連携待ちを切り上げます。パーティーとアライアンスの両方を数え、フェイスは除きます。童子切安綱では照破、草薙剣モードONで草薙剣を装備中は無名、それ以外の両手刀では不動を使います。

切り替え時または自分の直前のWS着弾から6秒未満はTP2550、6秒経過後はTP1500で撃ちます。草薙剣モードONでアフターマスがないときの無名は、集中攻撃中もTP3000まで待ちます。技が使用可能で射程内にいることを確認し、着弾を確認できなければ次の技を送りません。1回の集中攻撃は6回・75秒までで、全自動との通算は300秒に12回までです。味方が減ると通常連携の始点待ちに戻ります。

### 全自動の上限
| 上限 | 値 | 達したとき |
| :--- | :--- | :--- |
| 1 回の連携 | 6 回・75 秒 | その連携を止める |
| 通算 | 300 秒のあいだに 12 回 | 間が空くまで始めない（`//sc start` の OFF → ON で記録を消す） |
| PT の始点だけ | 600 秒 | 自分の手動の始点か `//sc start` まで始めない |

* 1 回の連携の回数と秒数、PT の始点だけの秒数は、戦闘が終わったら数え直します（交戦を解いたとき。PT の始点だけの秒数は、前の PT の始点の敵が倒れた・いなくなったあとに別の敵で始点が来たときも）。PT の始点で入り直しても、同じ敵のあいだは 1 回の連携の回数と秒数を持ち越します。
* 通算の上限（300 秒に 12 回）は、戦闘をまたいで数え続けます。

カスタムルートには、通算の上限はありません（段の数だけ撃ちます。段の上限は 10）。

## 💻 コマンド（`//sc`・`//autosc`・`//autoskillchain`）

| コマンド | 説明 |
| :--- | :--- |
| `//sc stop`（`//sc abort`・`//sc off` も同じ） | 予約と進行を取り消して止める（全体機能を OFF にして保存する。読み込み直しても OFF のまま） |
| `//sc start`（`//sc on` も同じ） | 止めたのを再開する（OFF → ON のときは、全自動の通算と PT の始点だけの記録も消す） |
| `//sc toggle` | 全体機能の ON / OFF を切り替える |
| `//sc reset`（`//sc clear` も同じ） | 予約を取り消し、初段待機に戻ってWSの送信経路を判定し直す。同じエリアでGearSwapを無効にした後は、このコマンドを1回実行する |
| `//sc route <番号>` | ルートを切り替える（`data/sc_routes.json` にある番号） |
| `//sc route` | 選んでいるルートを表示する |
| `//sc route reload` | `data/sc_routes.json` を読み直す（失敗したら前のルートのまま） |
| `//sc route fix` / `//sc fix` | 設定ファイルを既定のルートに戻す。ファイルがあるときは確認を求める |
| `//sc route fix confirm` / `//sc fix confirm` | 30 秒以内に入力すると、今のファイルを `data/sc_routes_backup_日時.json` に残してから既定のルートで上書きする |
| `//sc delay <1.0〜8.0>` | 待ち時間を、すべてのルートで上書きする |
| `//sc delay off` | 待ち時間の上書きをやめる（ルートの `delay_seconds` → 基本設定の順に戻る） |
| `//sc kusanagi` / `//sc kusanagi on` / `//sc kusanagi off` | 状態表示・有効化・無効化 |
| `//sc focus on` / `//sc focus off` | 集中攻撃を有効・無効にする |
| `//sc party` / `//sc solo` | パーティーの人の始点・自分の始点の ON / OFF |
| `//sc status` | 今の設定を表示する |
| `//sc reload` | アドオンを読み込み直す（全自動の通算・送った技の記録も消える） |

## 🗂 ルートの設定（`data/sc_routes.json`）

* 無い・空のときは、既定の 6 ルートで作ります。
* 読み込むときに中身を確かめます: ルートは 50 件まで・id は 1〜1000 の整数・`mode` は `custom` か `auto`・段は 10 件まで・`delay_seconds` は 1.0〜8.0・技名は日本語の名前だけ（英語の名前・一覧に無い名前のルートは飛ばす）。
* 起動時に読めないときは、ルートを空にして何もしません（内蔵の既定のルートで黙って動きません）。`//sc route fix` で既定を書き出せます。
* `AutoSkillchain_GUI_Editor.html` をブラウザで開くと、ルートを編集して `sc_routes.json` を書き出せます。

    * 選んだルートが無いときは、既定のルートに戻さず何もしない（`//sc route <番号>` で選ぶ）。

Version 5.3 follows openers from your party, checks the target before sending a weapon skill, and cancels pending actions on disengage. Weapon skill names use the Japanese client. Checks used Lua 5.1 with simulated Windower events. In-game behavior and the editor UI remain unverified.

- **v5.2 (2026-10-28)**

  - 連携の組み合わせ表の誤り 3 組を直した(硬化 → 振動 は分解、核熱 → 重力 は重力、湾曲になるのは貫通 → 切断)。

  - 初段の技が外れたとき、または初段の技がそれ自体で連携を起こした (前の技の続きになった) ときは、ルートを始めないようにした。これまでは始めてしまい、次の技が必ず連携不成立になっていた。
