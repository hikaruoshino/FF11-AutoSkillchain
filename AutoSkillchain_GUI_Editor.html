📌 保存・適用の手順:
1. 「JSONを開く」で Windower4/addons/AutoSkillchain/data/sc_routes.json を開きます (初回は上の「保存先のパス」をコピーして、ダイアログのファイル名の欄に貼り付けると早く開けます。2 回目からは前回のフォルダが出ます)。
2. 編集して「JSONを保存」を押すと、開いたファイルへそのまま上書きします (対応していないブラウザでは従来どおりダウンロードになるので、上のフォルダへ置いてください)。
3. FF11ゲーム内で //sc route reload または //sc reload を実行すると適用されます。
4. 使うルートの選択は ゲーム内の //sc route <番号> で行います (JSON の active_route は、設定の番号が JSON に無いときだけ使われます)。
